# Quickstart: 004-admin-web

验收管理后台页面和补上的管理接口。前置：feat 2、feat 3 已在本分支的基线上，身份服务可登录，`make admin` 与 `make admin-web` 能起。联盟密钥不是本页的前置；同步重试若上游失败，页面仍要看到审计和固定失败文案。

## 1. 登录

1. 打开 `http://127.0.0.1:5183/`。
2. 未登录时应去身份服务，页面上没有账号密码框。
3. 登录成功后停在工作台，地址不是 `/v1/users`。
4. 浏览器可读写存储和地址栏里没有 access_token。开发者工具里业务请求带 Cookie，请求头没有 `Authorization`。

未登录直接打开 `http://127.0.0.1:5183/orders`，看不到订单。登录后应回到该地址。

## 2. 菜单

登录后左栏能打开信息架构里的每一项，刷新仍停在该页。会话、工单、知识库、审计、同步游标在库空时是空表，不是「尚无接口」。

工作台三个数字与下面三个查询一致。没有数据时为 0：

- 同步失败的平台数
- 工单行数
- 待审提现数

## 3. 三处修改后再读

用页面各改一次，再用对应的 GET 核对，不要只看刚保存的提示：

1. 一条提示词正文。条目数仍是 8，不能新增 key。
2. 一条推荐问题的文案。列表里是新文案。已有 12 条上架时，再上架被拒绝。
3. 一个模型的权重，密钥留空。列表权重是新值，响应里没有密钥全文，只有末四位或全掩码。

抽查这三次的响应和表格：没有联盟 PID，没有完整收款账号。

## 4. 订单和用户

订单表同时有媒体返佣和用户分成。用户列表手机号脱敏，详情是完整手机。详情里的对话、订单、流水、工单只属于这个用户。授权状态没有 PID。

## 5. 五页操作

1. 打开一条会话，能看见消息，没有编辑用户话的控件。
2. 回复一条未关闭工单：状态不变，处理记录多一条。再把状态改为已关闭：多一条状态变更。
3. 知识库新增一条后能在列表看到。下架后列表仍在，状态为停用，现有检索不再返回它。
4. 审计表能看到刚才的提示词修改或同步重试，没有密钥。
5. 同步页只有四个平台。对其中一个点重试：审计有 `order.sync.retry`。传入 `meituan` 被拒绝。

## 6. 海报和用户视角

海报预览在浏览器里出现贴进矩形的二维码。网络面板里没有向服务端要合成图的请求。

用户视角关闭时，签发失败。本地若已开启，只看到成功提示，审计有这一条。两种情况下页面上都不出现凭证，也不打开消费者页面。
