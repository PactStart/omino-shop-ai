# Quickstart: 005-agent

验收助手是否按规格作答。页面不在本功能。命令在仓库根目录执行。前置是 feat 2 和 feat 3 已在当前分支的祖先上，PostgreSQL 与 Redis 已启动。

## 1. 单元测试

助手：

```bash
cd services/agent && uv sync && uv run pytest
```

期望：路由覆盖每条点分意图；把握低于 0.6 时不调用搜索；超过 6 条只产生合集卡；订单物流为空时话术含「未知」且不含媒体佣金；取消使图结束且不写半截检查点；追踪关闭时图仍能结束。测试日志不含密钥。

购物服务：

```bash
cd services/java && mvn -pl shop-api-app -am test -DskipITs
```

期望：送往助手的 JSON 使用 `model`，并带上提示词、链接或恢复载荷；local 在连接失败时仍是固定问候；连接成功时转发助手事件；取消会关闭内网流。

## 2. 本地对话

另开终端启动助手，再启动 APP。助手没启动时，下面第 3 步应仍得到固定问候 `你好`，终态意图是 `chitchat`。助手启动后，同一句话必须变成真实意图。

```bash
make agent
make app
```

用已有手机号登录拿到访问令牌。库里要有八条非空提示词。本地可以没有可分流模型，此时助手使用 `OPENAI_*`。没有这组环境变量时，本步只验证单元测试，不把空模型当成失败。

## 3. 买纸巾

```bash
curl -s -X POST http://127.0.0.1:8181/api/app/v1/chat/turns \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"clientMsgId":"cmsg-tissue-1","inputType":"text","text":"我要买纸巾"}'
```

用返回的 `runId` 读取事件，直到终态：

```bash
curl -N http://127.0.0.1:8181/api/app/v1/chat/runs/$RUN_ID/events \
  -H "Authorization: Bearer $TOKEN"
```

期望：有 `intent`，且 `intent` 为 `shop.search`。随后要么最多 6 张商品卡，要么 1 张合集卡。卡片标题和价格能在同一次搜索结果里找到。自拟商品为 0。

再发一句只有「买」的话。期望出现追问，商品卡和合集卡都是 0。

先让助手记住预算 200，再发「我要买纸巾」。期望搜索带上 200。接着改口说预算 50。期望这次搜索使用 50。

只发一条商品链接、不带文本。期望被受理。只发文本类型却把正文留空。期望被拒绝。

## 4. 订单与停止

对一笔无物流的本人订单提问。期望话术出现未知，用户分成出现，媒体佣金不出现。

另开一轮长回复。刷新阅读后重新带上最后一条事件编号。期望生成继续，终态不是 `cancelled`。

再开一轮，中途：

```bash
curl -s -X POST http://127.0.0.1:8181/api/app/v1/chat/runs/$RUN_ID/cancel \
  -H "Authorization: Bearer $TOKEN"
```

期望终态为 `cancelled`，停止前的文字还在，没有授权卡。

## 5. 授权、知识库、追踪

说「淘宝怎么授权」。期望一张授权卡，未完成前授权状态不变。带回确认的下一句告知授权完成，不再识别一次新意图，授权卡仍是 1 张。

对已授权平台说取消。未确认时状态不变。确认后状态改变 1 次，取消工具只调用 1 次，不再出现第二张确认卡。

问一条知识库没有的规则。期望明确未命中，并引导建单，不出现商品卡。

同一轮连续上报累计 100 token 和累计 150 token。期望按 150 结算，不按 250 扣。把 150 再送一次，新增扣费为 0。

生产配置下把追踪关掉再调用助手。期望不进入图。本地关掉追踪时，第 3 步仍能结束。抽查助手日志和追踪，模型密钥、联盟密钥、PID 的出现次数为 0。异常日志里不出现调用正文。

生产上回退是停掉助手进程。下一轮终态为错误，商品卡张数为 0。本地只有在连不上助手时才回固定问候，不能拿这句问候当生产回退。
